```bash
pip install lxml>=5.0.0
```

### 2. DCF Valuation Extraction Failing
**Status:** Needs fix, but non-blocking for MVP

**Error:**
```
ERROR: Error extracting DCF inputs for NVDA/JPM:
1 validation error for DCFInputs
fcf_history
  Input should be a valid list [type=list_type, input_value=None, input_type=NoneType]
```

**Impact:**
- DCF-based price targets showing "not available"
- Manager synthesis LLM is generating targets ($245/$205/$155 for NVDA)
- Reports fall back to LLM-generated targets (working)

**Root Cause:**
- `sec_edgar_parser.py` extracting DCF inputs returns `None` for `fcf_history`
- Pydantic validation expects a list, gets None
- Model validation fails before DCF calculation runs

**Fix Required:**
- [research_swarm/agents/fundamentalist/sec_edgar_parser.py](research_swarm/agents/fundamentalist/sec_edgar_parser.py:64-68)
- Ensure `fcf_history` defaults to empty list `[]` instead of `None`
- OR: Update prompt to extract FCF history more reliably

**Priority:** MEDIUM - Price targets still generated by Manager synthesis

### 3. Valuation Metrics Showing "Not Available"
**Status:** Expected limitation with free data sources

**Impact:**
- Reports show: "Valuation metrics not available for this ticker via free data sources"
- SEC-derived fallback (P/E from filings) not displaying in template

**Fix Required:**
- Verify `get_valuation_metrics()` or SEC fallback is populating data
- Check template rendering logic for valuation section
- May need to update template to show SEC-derived values

**Priority:** LOW - VGM Value score is calculated correctly (7.2 for JPM, 3.5 for NVDA)
